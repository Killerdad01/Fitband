# FitBand Android app

Open this folder in Android Studio and run it on an Android phone.

Included:
- Fitness dashboard
- Daily weight entry
- BMI calculation
- Weight history
- Adaptive workout recommendation logic
- Workout UI
- Profile
- Bluetooth permissions ready for Mi Band 3 integration

Important: Mi Band 3 BLE protocol is not assumed here. The next implementation step is the actual Mi Band 3 GATT/protocol layer so the app can read the band rather than inventing readings.
